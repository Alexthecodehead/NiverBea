SITE DO CONVITE — BEA'S BIRTHDAY

Arquivos:
- index.html: site pronto em arquivo único. Pode abrir direto no navegador.
- assets/bea-foto.jpeg: imagem original otimizada para web. O index.html já vem com a imagem embutida, então este arquivo fica apenas como backup.

Como publicar:
1. Extraia este ZIP.
2. Suba o arquivo index.html em uma hospedagem estática, como Netlify, Vercel, GitHub Pages, Hostinger ou Lovable.
3. Se quiser editar os links, procure no HTML por "Lista de presentes" e "Lista de livros".
