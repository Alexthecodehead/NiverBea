Site de aniversário da Bea

Arquivos:
- index.html -> convite principal
- presentes.html -> página com sugestões de presentes e livros
- assets/bea-foto.jpg -> foto usada no convite

Para publicar:
1. Envie todos os arquivos desta pasta para a sua hospedagem.
2. Defina o arquivo index.html como página inicial.
3. Mantenha a pasta assets junto dos arquivos HTML.
